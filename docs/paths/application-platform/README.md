# Application platform path

## Purpose

Use this path for capabilities that host, build, and run applications on top of
the shared private-cloud foundation.

This is where development services, source control, CI/CD, registries,
Kubernetes, GitOps, and future application runtime patterns belong.

## Current guides

- [Development platform path](development.md)
- [Kubernetes platform path](kubernetes.md)

## How this path grows

Add deeper GitOps, runner, registry, and cluster guides here when those setups
are introduced. They should consume shared identity, PKI, Vault, cache, edge,
and system-control services when those are available instead of redeploying
their own foundations.
