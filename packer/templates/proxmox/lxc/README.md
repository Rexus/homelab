# Proxmox LXC templates

Use Terraform or Proxmox-native templates for LXC creation.

Packer in this repository currently targets VM image workflows. For LXC, prefer:

- Proxmox container templates from the host or storage
- Terraform-driven LXC provisioning

Read more in:

- [Terraform](../../../../terraform/README.md)
- [Proxmox reference platform](../../../../docs/platforms/proxmox/README.md)
